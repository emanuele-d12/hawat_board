# To-Do List con Drag & Drop - Vue.js

## 📋 Descrizione del Progetto

Applicazione To-Do List con gestione categorie e drag & drop per spostare le task tra le sezioni.

## ✨ Caratteristiche

- **Input testo** per inserire nuovi compiti
- **3 categorie selezionabili** tramite bottoni:
  - `Quotidiane`
  - `Questa settimana`
  - `Todo`
- **Pulsante "Aggiungi"** per inserire il compito nella categoria selezionata
- **3 sezioni visive** per visualizzare le task per categoria
- **Drag & Drop** per spostare le card tra le categorie con il mouse

## 🎯 Tecnologie

- **Vue.js 3** (Composition API)
- **Tailwind CSS** (styling utility-first)
- **Drag & Drop nativo** (HTML5 Drag API)
